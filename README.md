# Keenetic Route Manager

**Keenetic Route Manager** — бесплатная программа для Windows с графическим интерфейсом, предназначенная для просмотра и управления статическими IPv4-маршрутами на роутерах Keenetic. Она помогает распределять трафик между обычным интернет-подключением (**ISP**) и VPN-интерфейсами, в том числе AmneziaWG/WireGuard, без ручного ввода большого количества команд CLI.

Программа использует PySide6 (Qt), работает с роутером через Telnet в локальной сети и подходит для конфигураций с тысячами маршрутов.

**Актуальная версия:** [0.2.4 — Windows x64](https://github.com/Nakortanax/Keenetic-Route-Manager/releases/tag/v0.2.4). Готовый EXE запускается без установки Python.

## Возможности программы

### Управление маршрутами
- Чтение статических IPv4-маршрутов из конфигурации Keenetic.
- Просмотр большого списка маршрутов в таблице с поиском, сортировкой и фильтрацией.
- Отбор маршрутов по интерфейсу, IP-адресу и другим доступным параметрам.
- Добавление, изменение и удаление поддерживаемых статических маршрутов.
- Выбор интерфейса подключения: обычный интернет (ISP) или настроенный VPN.
- Предварительный просмотр CLI-команд перед применением изменений.
- Защита неподдерживаемых и потенциально опасных маршрутов от автоматического редактирования.

### Работа с сайтами
- Поиск IPv4-адресов сайта по доменному имени (DNS A-записи).
- Определение маршрутов, действующих для найденных адресов.
- Переключение маршрутов сайта между ISP и VPN.
- Создание точных исключений **/32** без удаления общих подсетей **/16** и **/24**.
- Обнаружение конфликтующих записей, когда один IP указан через несколько интерфейсов.
- Контролируемое устранение конфликтов /32 с выбором интерфейса, который нужно оставить.

### Безопасность изменений
- Подтверждение плана изменений пользователем.
- Создание локальной резервной копии списка маршрутов перед записью.
- Повторное чтение конфигурации для обнаружения изменений, сделанных вне программы.
- Проверка итоговой таблицы маршрутов перед сохранением настроек Keenetic.
- Попытка отката изменений при ошибке, с сообщением о результате проверки.
- Запрет автоматического сохранения при неуспешном применении плана.

### Диагностика и удобство
- Журнал Telnet: отправленные команды, очищенные ответы роутера, ошибки и действия программы.
- Сохранение журнала между запусками, просмотр и экспорт для диагностики.
- Маскирование паролей и ключей в диагностических данных.
- Подсказки при наведении курсора на элементы интерфейса.
- Современная тёмная тема с разделами «Обзор», «Маршруты», «Сайты», «Импорт/экспорт» и «Диагностика».
- Локальные подписи и заметки для IP-адресов — без изменений на роутере.
- Импорт и экспорт списков маршрутов в поддерживаемых форматах, в том числе CLI/BAT, CSV и JSON.

## Скачать и установить

1. Откройте страницу [Releases](https://github.com/Nakortanax/Keenetic-Route-Manager/releases).
2. Скачайте **KeeneticRouteManager.exe** или архив **KeeneticRouteManager-0.2.4-Windows-x64.zip**.
3. При необходимости проверьте SHA-256 по файлу **SHA256SUMS-release.txt** из того же релиза.
4. Запустите EXE, укажите адрес роутера и данные доступа к CLI.
5. Проверьте подключение, загрузите маршруты и изучите предварительный план, прежде чем сохранять изменения.

**Требования:** Windows 10/11 x64, доступ к Keenetic по Telnet из доверенной локальной сети, учётная запись с необходимыми правами. Установленный Python для готового EXE **не требуется**.

## Важные ограничения

- **Telnet передаёт данные без шифрования.** Используйте программу только внутри доверенной локальной сети. Не открывайте Telnet-порт роутера в интернет.
- Один IP-адрес может обслуживать несколько сайтов (например, через CDN). Переключение IP влияет не только на один домен.
- Наличие статического маршрута не гарантирует фактический путь каждого пакета: на него могут влиять политики и приоритеты маршрутизации Keenetic.
- Автоматический откат при сетевом сбое или ошибке роутера **не гарантирован**. После ошибки проверьте фактические маршруты по диагностическому журналу.
- Журналы, локальные подписи IP и резервные списки маршрутов могут содержать частную информацию о сети. Не публикуйте их без проверки.
- Поддерживаются статические **IPv4**-маршруты; программа не является универсальной системой настройки роутера.
