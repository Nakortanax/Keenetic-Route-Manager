# Keenetic Route Manager

**Windows IPv4 static route manager for KeeneticOS** · version **0.2.3** · PySide6 / Qt.

> Third-party community utility, not affiliated with or endorsed by Keenetic Ltd. The visual style is inspired by router control panels; no Keenetic logos, proprietary fonts, or firmware assets are bundled.

## Возможности

- Современная тёмная тема с боковой навигацией: Обзор, Маршруты, Сайты, Импорт/экспорт, Диагностика.
- Читать `show running-config` и `show interface` через Telnet в доверенной локальной сети; отображать тысячи записей через `QTableView` и сортируемую модель.
- Группировка/фильтрация по интерфейсу, поиск по IPv4, сайту, интерфейсу, сетевому владельцу.
- Добавить, изменить, удалить статические IPv4-маршруты с предпросмотром команд.
- «Найти сайт»: DNS A-записи, существующие покрывающие маршруты, выбор `ISP` или `Wireguard2` и безопасные исключения `/32`.
- Локальные подписи IP (без записи на роутер); резервная копия маршрутов перед изменениями; повторное чтение и сверка до `system configuration save`.
- Экспорт BAT, CLI, CSV, JSON, импорт BAT/CLI/CIDR с проверкой конфликтов.
- `ip route disable`, unsupported gateway/reject/default routes — видны, но защищены от автоматического изменения.

## Запуск на Windows

1. Установи **Python 3.11+** (отметь *Add Python to PATH*) и разреши установку PySide6 из сети.
2. Распакуй архив и запусти `start_windows.cmd` (он создаёт `.venv` и ставит зависимости).
3. Для сборки EXE в Windows PowerShell: `./build_windows.ps1`. Готовый файл: `dist/KeeneticRouteManager.exe`, рядом SHA-256.
4. Вводи адрес и пароль Keenetic; пароль хранится только в памяти процесса, на диск не сохраняется.
5. Сначала **Проверить связь**, затем **Обновить маршруты**. Для сохранения изменений программа запросит подтверждение.

## Безопасность и ограничения

- **Telnet не шифрует пароль.** Используй только в доверенной LAN; никогда не открывай порт 23 в интернет. SSH-клиент для роутера в этой версии не реализован.
- Приложение **не хранит** `show running-config` целиком или закрытые ключи. Локальные JSON содержат только маршруты и названия сайтов; эти данные могут быть чувствительными — никогда не публикуй свои локальные файлы.
- Не даёт гарантии, что IP однозначно принадлежит конкретному сайту; серверы/CDN обслуживают много доменов. Программа добавляет только IPv4 A-записи, полученные локальным DNS.
- Из-за приоритетов и политик маршрутизации Keenetic наличие статического маршрута не гарантирует фактический путь каждого пакета.
- При переходе с широкого префикса на другой интерфейс используется точный маршрут `/32`, общая подсеть не удаляется.
- При ошибках чтения запись заблокирована; неизвестные строки нельзя молча игнорировать.
- При ошибке изменения **сохранение не вызывается**, но CLI Keenetic может уже иметь изменения в текущей конфигурации. Проверь их вручную и при необходимости восстанови по резервному списку. Бэкап содержит только маршруты, не всю конфигурацию роутера.
- Программа ещё **не испытана на реальном Keenetic в версии PySide6**. Версия 0.1.7 (Tkinter) работала у пользователя; перенос GUI требует проверки.

## Локальные файлы (НЕ отправлять в GitHub)

- `%LOCALAPPDATA%\KeeneticRouteManager\metadata\192.168.1.1.json` — подписи адресов.
- `%LOCALAPPDATA%\KeeneticRouteManager\backups\routes-*.json` — резервные списки.

## Структура

- `main.py` — PySide6 GUI; `keenetic_manager/core.py` — парсер Keenetic CLI, маршруты и экспорт.
- `keenetic_manager/transport.py` — Telnet; `controller.py` — считывание, резервирование и транзакции.
- `keenetic_manager/site_routes.py` — проверка адресов сайта, безопасные планы смены интерфейса.
- `keenetic_manager/metadata.py` — локальные аннотации; `interface_choices.py` — допустимые интерфейсы.
- `tests/` — unit-тесты ядра и дополнительные smoke-тесты PySide6 (при установленной зависимости).

## Журнал Telnet и диагностика (0.2.2)

Страница «Диагностика» показывает последние события: подключения, действия пользователя,
отправленные команды CLI, очищенные ответы и ошибки. Локальные файлы журналов расположены
в `%LOCALAPPDATA%\KeeneticRouteManager\logs\activity.jsonl`; при заполнении
выполняется ротация до четырёх резервных файлов. Кнопки позволяют просматривать журнал,
копировать видимую часть и экспортировать **весь доступный локальный журнал**.

**Конфиденциальность:** пароль Telnet не сохраняется и не записывается при авторизации.
Из ответа `show running-config` в журнал попадают только строки `ip route ...`,
а не остальная конфигурация роутера. Из `show interface` сохраняются только описания
интерфейсов и сведения об их состоянии; строки с ключами отбрасываются. Записываются
IP-адреса и маршруты, поэтому файлы журнала могут раскрывать сетевые привычки —
не публикуй их на GitHub без проверки. Логи хранятся только на компьютере пользователя,
а не на Keenetic. Для диагностики доступны подсказки при наведении курсора на элементы управления.

Журнал **не заменяет** резервную копию маршрутов: перед записью приложение делает
отдельный локальный бэкап списка маршрутов и повторно проверяет результат на роутере.

## Исправление переключения сайтов (0.2.3)

На KeeneticOS 5.2 Beta 1 возможна ошибка `Io::Netlink ... file exists`, если попытаться добавить второй `/32` маршрут к одному IP на другой интерфейс до удаления старого. Версия 0.2.3 сначала удаляет исходный точный маршрут, затем добавляет замену. При ошибке она пытается откатить выполненные команды и проверяет состояние; `system configuration save` не вызывается. Двойные конфликтующие `/32` маршруты автоматически не исправляются: требуется ручная проверка.

После ошибки в 0.2.2 обязательно прочитай текущие маршруты `188.114.96.3/32` и `188.114.97.3/32`, прежде чем менять их снова.
